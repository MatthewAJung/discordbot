# Discord Bot
Personal discord bot created for friends

Cogs are added for specific use cases whenever required

# debtbot
A Cog dedicated to tracking who owes who automatically removing cycles of debt between people if possible.

# shivposting
A Cog dedicated to tracking statistics for memes sent among friends. Calculates averages of upvotes, who upvoted who, and returns graphics of these stats.

# wordle
A Cog dedicated to tracking statistics for Wordle performance in discord. Calculates average score, score over time, and returns graphics of these stats.
